# 🚀 SmartOps - Internal Developer Platform & Asset Management

SmartOps คือระบบบริหารจัดการทรัพยากร พนักงาน และกระบวนการทำงานภายในองค์กรแบบครบวงจร

## 🏗️ Architecture & Tech Stack

- **Backend:** Spring Boot (REST API)
- **Web Admin:** Next.js (React) + Tailwind CSS
- **Mobile App:** Flutter (iOS & Android)
- **Database:** PostgreSQL / Redis
- **DevOps:** Docker, GitHub Actions

## 📁 Project Structure

- `apps/backend`: RESTful API Services
- `apps/web`: Web Management Dashboard
- `apps/mobile`: Employee Mobile Application
- `docs`: System Specification & API Specs
